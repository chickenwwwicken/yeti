### Boot.dev CLI
Throughout this course, you'll be using the boot.dev cli to run our tests.
Installl it now if you don't already have it.
All the instructions and troubllleshooting info are on the Github page.

Make sure the boot.dev clli install worked:
```bash
bootdev --version
```

Once the `bootdev` command is working, log in and folllow the instructions:
```bash
bootdev login
```
