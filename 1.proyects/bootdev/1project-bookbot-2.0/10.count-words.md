Time for our first bit of data analysis! Let's count the words in the book.

## Assignment

1. [ ] Write a new function that accepts the text from the book as a string, and returns the number of words in the string. The [.split() method](https://docs.python.org/3.3/library/stdtypes.html?highlight=split#str.split) will be helpful here.
2. [ ] Instead of printing the books contents, print this message to the console:

```
{num_words} words found in the document
```

Replace `{num_words}` with the actual number of words in the book.

**Run and submit** the CLI tests.


Run the CLI commands to test your solution.

1. python3 main.py
    - Expecting exit code: 0
    - Expecting stdout to contain all of:
        
        - 75767 words found in the document

### main.py
```python
def main():
    book_path = 'books/frankenstein.txt'
    text = get_book_text(book_path)
    print(count_words(text))

def count_words(text):
    return f"{len(text.split())} words found in the document"

def get_book_text(path):
    with open(path) as f:
        return f.read()

main()
```
