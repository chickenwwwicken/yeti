[Refactoring](https://en.wikipedia.org/wiki/Code_refactoring) is a fancy word for 
"rewriting your god-awful code so it's not so terrible." 
Refactoring doesn't change the _behavior_ of your code, just the _way it's written_.

Let's refactor our project to use multiple Python files. 
Not only will it be useful for you to learn how to split code across files, 
but in this case, it will help us organize our code. 
We'll use this structure:

- `main.py` - The entry point to our program and any code that doesn't fit elsewhere
- `stats.py` - A file that contains functions for analyzing the text

## Assignment

1. [ ] Move your function that counts the words into a new `stats.py` file.
2. [ ] Import the function in your `main.py` file, it will look something like this:

```py
from stats import get_num_words
```

_Where `stats` is the name of the file (without the `.py` extension) and `get_num_words` is the name of the function you want to import._

**Run and submit** the CLI tests.


Run the CLI commands to test your solution.

1. python3 main.py
    - Expecting exit code: 0
    - Expecting stdout to contain all of:
        
        - 75767 words found in the document
        
2. cat main.py
    - Expecting exit code: 0
    - Expecting stdout to contain all of:
        
        - from stats import

### main.py
```python
from stats import *

def main():
    book_path = 'books/frankenstein.txt'
    text = get_book_text(book_path)
    print(get_num_words(text))

def get_book_text(path):
    with open(path) as f:
        return f.read()

main()
```

### stats.py
``` python
def get_num_words(text):
    return f"{len(text.split())} words found in the document"
```
