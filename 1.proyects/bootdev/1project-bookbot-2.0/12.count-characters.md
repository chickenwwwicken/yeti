Ah, the meat of bookbot: counting characters!

## Assignment

1. [ ] Add a new function to your `stats.py` file that takes the text from the book as a string, and returns the number of times each character, (including symbols and spaces), appears in the string.
    - Convert any character to lowercase using the [`.lower()` method](https://docs.python.org/3/library/stdtypes.html#str.lower), we don't want duplicates.
    - Use a dictionary of `String` -> `Integer`. The returned dictionary should look something like this:

```
{'p': 6121, 'r': 20818, 'o': 25225, ...
```

2. [ ] Import and call the function in `main.py`, and capture the result in a new variable.
3. [ ] After printing the word count, print the dictionary of characters and their counts.

**Run and submit** the CLI tests

1. `python3 main.py`
    - Expecting exit code: 0
    - Expecting stdout to contain all of:
        
        - `'t': 29493`
        - `'p': 5952`
        - `'c': 9011`

### main.py
```python
from stats import *

def main():
    book_path = 'books/frankenstein.txt'
    text = get_book_text(book_path)
    print(get_num_characters(text))

def get_book_text(path):
    with open(path) as f:
        return f.read()

main()
```

### stats.py
``` python
def get_num_words(text):
    return f"{len(text.split())} words found in the document"

def get_num_characters(text):
    char_dict = {}
    for char in text.lower():
        if char in char_dict:
            char_dict[char] += 1
        else:
            char_dict[char] = 1
    return char_dict
```
