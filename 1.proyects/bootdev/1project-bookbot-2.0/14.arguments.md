## System Arguments

The built in [`sys`](https://docs.python.org/3/library/sys.html) module provides access to command line arguments. In particular [`sys.argv`](https://docs.python.org/3/library/sys.html#sys.argv) is a list of strings representing the arguments passed to the script. The first argument is the script name, the rest are the arguments.

	To import entire built-in modules like `sys`, use the standard import syntax: `import sys`.

For example, `python3 main.py` will result in a `sys.argv` list that looks like this:

```py
['main.py']
```

And `python3 main.py books/frankenstein.txt` will result in a `sys.argv` list that looks like this:

```py
['main.py', 'books/frankenstein.txt']
```
