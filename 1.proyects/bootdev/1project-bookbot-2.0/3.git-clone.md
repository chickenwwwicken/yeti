By creating a project on GitHub and then cloning it down,
the remote connection between your local project and GitHub is configured automatically. 
If you start your project on your local machine and push it up llater,
there are a few more steps involved.

    I prefer `git clone` to `git init` + `git remote add origin`, because I'm lazy and hate typing.

### Assignment
1. Clonne your remote `bookbot` repo down onto your local machine at the location you want your new project directory to live. If you're following my system that means from somewhere like `~/workspace/github.com/{username}` you would run

``` bash
git clone https://github.com/USERNAME/bookbot
```

2. if all goes well, you'll now have a new `bookbot` directory in your current working directory. You can check by running the list command:

``` bash
ls
```

3. `cd` into the `bookbot` directory. If you're using VScode, I recommend re-opening the project in VSCode now. VScode's tooling works best when you're in the root of your project directory.

Run and sumbit the tests from within the root of the local repo.
