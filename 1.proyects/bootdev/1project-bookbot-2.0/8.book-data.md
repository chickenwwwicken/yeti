To be able to analyze a book, first we need to have a book to analyze!

### Assignment
"Frankenstein" by Mary Shelley is in the public domain, so let's start with that.

1. Create a directory in your `bookbot` project called `books`, and a new `books/frankenstein.txt` file.
2. Open a browser and navigate to project Gutenberg here. Copy and paste the entire contents of the page into your `frankenstein.txt` file.
3. Create a `.gitignore` file in your `bookbot` project root directory.
4. Add the `/books` directory to your `.gitignore` file. It's typically best practice to only commit code to your repository, not data.

We don't want to save the entire book in our Git repository. Generally speaking, Git is for code, not for data.
If you're using VSCode, you should see the filename turn dark gray in your file explorer.

Run and submit the CLI tests.


Run the CLI commands to test your solution.

1. head books/frankenstein.txt
    - Expecting exit code: 0
    - Expecting stdout to contain all of:
        - Frankenstein; Or, The Modern Prometheus
        
2. cat .gitignore
    - Expecting exit code: 0
    - Expecting stdout to contain all of:
        - books
