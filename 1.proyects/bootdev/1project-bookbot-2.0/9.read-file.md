## with Block

A [with](https://docs.python.org/3/reference/compound_stmts.html#with) block can be used to [open a file](https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files):

```python
with open(path_to_file) as f:
    # do something with f (the file) here
```

_The `with` block will automatically close the file when the block is exited, cleaning up resources_.

## .read() Method

You can use the [.read()](https://python-reference.readthedocs.io/en/latest/docs/file/read.html) method to read the contents of a file into a string:

```py
# f is a file object
file_contents = f.read()
```

### main.py
```python
def main():
    book_path = 'books/frankenstein.txt'
    text = get_book_text(book_path)
    print(text)

def get_book_text(path):
    with open(path) as f:
        return f.read()

main()
```
