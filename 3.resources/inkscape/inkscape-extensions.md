## export > export layer slices
export multiple objects as separate files
1. create layer called "slices"
2. draw rectangles on all objects you want to export
3. you can create rectangles fitting objects automatically:
    1. generated from path > frame...
    2. set the color of the field and stroke to transparent
    3. export it
