### import image
make sure image same size as document
CTRL SHIFT R

### create new layer
layer 1 - image
layer 2 - new layer

### create the object you wanna clone all over
can be whatever
in fill and stroke menu, "unset painnt"
make it black by default
enables object to read whatever underneath

### align object
align it to the top right corner of the page

### create tiled clones
considering the width and height of the image
edit > clone > create tiled clone
symmetry > add width and height
trace > enable trace
trace > 3. enable color
trace > 3. disable anything else
make sure to have the object selected.
